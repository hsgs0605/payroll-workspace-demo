# 페이롤 — 급여 처리 MVP

[웹 시연 바로가기](https://hsgs0605.github.io/payroll-workspace-demo/)

직원 100여 명·단일 사업장 환경을 가정한 한국어 급여 웹 데모입니다. **104명의 가상 직원**으로 급여 입력 → 검토 → 마감 → 급여대장·명세서 출력 과정을 시연합니다.

## 사용 방법

1. `3분 시연 시작`을 선택하거나 급여대장에서 직원을 선택합니다.
2. 기본급·식대·추가 수당·상여 및 세금·사회보험 공제 금액을 수정합니다.
3. 공제 금액을 확인하고 `내역 확인 완료`를 체크한 후 저장합니다. 금액을 바꾸면 기존 확인 표시는 해제됩니다.
4. `급여 검토`를 실행해 검토함의 모든 내역을 확인합니다. 처음에는 4명의 검토 내역이 있습니다.
5. 오류와 미확인 내역이 없어지면 `급여 마감`을 선택합니다. 저장 후 검토를 다시 실행해야 마감할 수 있습니다.
6. `급여대장 다운로드`로 전체 직원의 CSV를 받습니다. 직원 상세에서 `급여명세서 인쇄`를 선택하고 브라우저 인쇄창에서 PDF로 저장할 수 있습니다.

월별 데이터는 독립적으로 저장됩니다. 새로운 월은 가상 데이터로 시작합니다. 마감된 월은 입력·가져오기를 잠그며 `마감 해제` 후 수정할 수 있습니다. `시연 데이터 초기화`는 모든 월의 브라우저 데이터를 초기화합니다.

## 계산 범위

- 지급액 = 기본급 + 식대 + 추가 수당 + 상여
- 공제액 = 국민연금 + 건강보험 + 장기요양 + 고용보험 + 소득세 + 지방소득세 + 기타 공제
- 실지급액 = 지급액 − 공제액

**공제·추가 수당은 담당자가 확인한 금액을 입력합니다.** 예시 금액은 법정 요율로 계산한 값이 아닙니다. 세금·사회보험 자동 산정, 통상임금·시간외수당 계산, 연말정산, 세무 신고는 이 MVP에 포함되어 있지 않습니다. 현재 명세서는 시연용이며 실제 교부에는 회사 기준 및 법정 기재사항을 반영해야 합니다.

검토 시 공제 확인 여부, 실지급액의 전월 대비 10% 이상 변동, 공제 초과, 지급액 0원을 확인합니다. 변동 알림은 담당자 확인으로 해소할 수 있지만 입력 오류는 반드시 수정해야 합니다. 지급 금액은 원 단위 정수로 처리합니다.

## CSV 입력

사용 가이드나 가져오기 창에서 입력 양식을 내려받습니다. UTF-8 CSV만 지원합니다. 사번 중복, 누락 열, 잘못된 금액·인코딩은 거부합니다. 최대 500명·1MB입니다.

가져오기는 **현재 월의 직원 목록 전체를 교체**합니다. 모든 직원은 다시 검토해야 합니다. 다운로드한 급여대장도 다시 가져올 수 있습니다. 엑셀에서 수식으로 실행될 수 있는 문자열은 내보낼 때 보호합니다.

## 실행·검증

Node.js 22 이상에서 외부 패키지 설치 없이 실행합니다.

```sh
node scripts/serve.mjs
```

브라우저에서 `http://127.0.0.1:4173`을 여세요.

```sh
node --test tests/payroll.test.mjs
node --check dist/app.mjs
```

## GitHub Pages

`dist`가 공개 웹사이트입니다. 저장소 Settings → Pages에서 Source를 **GitHub Actions**로 설정하면 `main` 브랜치 변경 시 `.github/workflows/pages.yml`이 테스트 후 배포합니다. 모든 경로는 상대 경로로 작성되어 저장소 하위 경로에서도 동작합니다.

## 저장·운영 범위

입력 자료는 해당 브라우저의 `localStorage`에만 저장됩니다. 서버로 전송하거나 다른 PC와 동기화하지 않습니다. 공개 시연에는 가상 데이터만 사용하세요. 저장 공간이 차단되거나 부족하면 화면에 안내합니다.

실제 회사 운영으로 전환할 때는 로그인·권한, 서버 DB, 변경·승인 기록, 암호화·백업, 회사 급여규정, 귀속연도별 계산 기준을 추가해야 합니다. 현재 마감은 데모 화면의 수정 잠금이며 서버에서 보장하는 승인 기능이 아닙니다.

## 파일 구성

- `dist/index.html`: 한국어 화면 및 접근성 구조
- `dist/styles.css`: 반응형 화면·인쇄 양식
- `dist/app.mjs`: 월별 상태, 직원 입력, 검토·마감, 시연 가이드
- `dist/payroll-core.mjs`: 원 단위 계산·검증·CSV 처리
- `tests/payroll.test.mjs`: 계산·마감·CSV 핵심 검증

다음 개발 후보: 기존 급여 엑셀 양식 연결, 세금·보험 산정, 회사별 급여항목·계산 기준, 인사정보·근태 연계.
